# prefixgate

The prefixgate dashboard as a static page: replays of the real, recorded runs, exported by
`scripts/static_space.py`. Source, method and results:
[github.com/Sebastianrodaaa/prefixgate](https://github.com/Sebastianrodaaa/prefixgate).

- **agent tab (opens first): replays.** The 24 runs in `results/agent_runs.json` are replays of a real, recorded CPU
  run: Llama 3.2 3B Instruct (`unsloth/Llama-3.2-3B-Instruct@006f5dc`, fp32, greedy, 8 threads) wrote each tool call
  and the trained Qwen2.5-0.5B gate scored every prefix. Nothing on this page is generated by Llama now.
- **replay tab: replays.** The 776 held-out Policy Gates calls from the committed run, at all four risk levels.
- **No live model here.** A static Space has no server, so the live tab (paste a call, the Qwen gate scores it) and
  the live agent are off. Even on a 2 vCPU server the live agent would be slow: one Llama 3.2 3B call took 36 s on 2
  threads pinned to 2 cores (`git-status`, `rm-rf-home`) against 11 to 28 s on 8; Llama 3.2 1B took 20 to 22 s but
  wrote the wrong tools, e.g. a Stripe transfer for `rm -rf`. Run everything locally with `make demo`, or the
  container in `space/Dockerfile` (Docker Spaces need HF PRO).

Nothing is executed: allow, deny and escalate only change what the page shows.
